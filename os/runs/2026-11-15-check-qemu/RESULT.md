# `check`: one screen, one photo (15 Nov 2026, emulator)

For the next run on the HP: one command that says how the machine and Turiya are, on one screen, reading only.
It never touches the internal SSD (`disk` waits for its owner's yes).

It shows: heart, breath, the keyboard organ, the two judges; processor, memory, screen; the PCI functions that
matter for drivers (NVMe, SATA, USB 3/4, display, network, audio); ACPI and whether power-off is known; every
USB controller (a Nadi each) with what is plugged in; and, if a stick is there, its top folder through Smrti.

Emulator (two USB controllers, a FAT32 stick on the second, an NVMe disk): see `serial_check.txt`, 15 lines.
